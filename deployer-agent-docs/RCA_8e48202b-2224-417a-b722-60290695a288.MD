## Root cause

This is expected rolling-deploy behavior on tier_0, not a defect. Since promote at 03:27:01 the app serves normally on both the emergent.host URL and the custom domain.

## Recommendation
- Re-test now with a hard refresh / incognito to clear any stale bundle; the app is currently serving 200s on both URLs.
- If a brief unavailability during every deploy is undesirable, consider a higher tier (more replicas / faster startup) to shorten the rollout gap. Otherwise no action needed.
